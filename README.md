# Info
This script generates a HUB-3 PDF417 compliant barcode for banking purposes in Croatia. The script is using the [treepoem](https://github.com/adamchainz/treepoem) library to generate the barcode. You'll need to install the library and the dependencies (ghostscript) to use the script.

# Usage
Replace the values in the `data_to_encode` variable with the required information and run the script:
```bash
python3 generate_barcode.py
```
